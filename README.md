# Christian Portfolio

**Live Demo:** [christiand.vercel.app](https://christiand.vercel.app)

## Overview

A personal portfolio website showcasing my software engineering projects, technical skills, resume, GitHub, LinkedIn, and contact information.

## Features

- Full-screen single-page portfolio experience
- Smooth section transitions between Home, Projects, and Contact
- Project carousel for selected work
- Animated stats section
- Professional profile image section with rotating green accent ring
- Contact form UI
- Responsive design for desktop and mobile

## Featured Projects

- **CampusConnect**
- **InboxIQ**
- **MazeGrid Project**
- **Sudoku Project**

## Tech Stack

| Category | Tools |
|----------|-------|
| Framework | Next.js, TypeScript |
| Styling | Tailwind CSS |
| Animation | Framer Motion |
| Icons | Lucide React |
| Deployment | Vercel |

## How to Run Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Deployment

This project is deployed on [Vercel](https://vercel.com).
